# 信院小帮手 Skill 导入验证仓库

这是一个符合 [Agent Skills 规范](https://agentskills.io/specification) 的最小测试样例。仓库中的校园地点**全部虚构**，只用于检查豆包是否能从 GitHub 导入 Skill，以及导入后能否读取 `references/` 下的文件。这里没有真实校园资料，也没有商家、教师或联系方式数据。

## 文件

- `SKILL.md`：Skill 名称、适用场景与回答规则。
- `references/campus.md`：唯一的虚构地点记录和校验字符串。

## 在豆包中测试

1. 登录你要测试的豆包产品或版本，进入你看到的「技能包」或「技能」管理入口。
2. 如果该入口提供「从 GitHub 导入」「添加 GitHub 仓库」等选项，粘贴本仓库的 HTTPS 地址，按界面提示完成导入。若它要求填写 Skill 目录，本样例的 `SKILL.md` 位于仓库根目录。
3. 若界面只支持上传本地文件，可下载本仓库 ZIP，按界面说明选择包含 `SKILL.md` 的目录或文件；这只能验证本地导入，不能证明 GitHub 链接直装可行。
4. 导入后，新建对话并启用该 Skill。打开 `references/campus.md`，复制其中的“地点名称”，在豆包提问：“这个测试地点在哪里？请给出校验字符串，并注明资料性质。”
5. 对照 `references/campus.md` 检查回答：应包含该文件中的位置描述和校验字符串，并注明“虚构测试数据”。如果只识别了 Skill 名称或给出泛泛回答，可能没有读取参考文件。
6. 再问一个本文件未列出的真实校园地点。预期行为是说明缺少可靠资料，而不是编造位置。

## 结果怎么判断

- **导入入口接受仓库地址，且能回答参考文件内容**：该产品版本中的 GitHub 导入链路通过这次验证。
- **能导入 Skill，但读不到参考文件**：需要检查导入器是否包含 `references/` 目录，以及是否真正启用了 Skill。
- **没有 GitHub 导入入口**：不能据此断定所有豆包产品都不支持；记录产品名称、平台、版本与界面截图，再核对该版本的导入方式。

请不要把测试地点、路线或校验字符串用于真实校园问路。Agent Skills 规范描述文件结构，但不保证任意豆包版本提供 GitHub 一键安装。以你实际使用的豆包界面和测试结果为准。
